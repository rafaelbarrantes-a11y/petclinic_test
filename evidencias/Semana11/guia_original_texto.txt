VII.- INTRODUCCIÓN: 

En los proyectos de software es importante la calidad del software, la fase de testing es la que nos va a permitir controlar la calidad del software. Como primer paso de acuerdo al modelo agil de testing las pruebas unitarias deberán ser realizadas, en el presente laboratorio se dan las pautas para desarrollar pruebas unitarias con conexión a base de datos


VII.- PROCEDIMIENTO: 

Basado en las pruebas unitarias de la clase PetServiceTest  del proyecto :

 https://github.com/jgomezz/petclinic_test


CASO 1 :
Deberá realizar la pruebas unitarias de la tabla vets en la clase VetServiceTest en la aplicación peticlinic_test , es decir las pruebas unitarias de creación, actualización, búsqueda y eliminación de veterinarios. Todo esto deberá realizarse en coordinación con su equipo de trabajo usando Git

CASO 2 :
Deberá realizar la pruebas unitarias de la tabla owners en la clase OwnerServiceTest en la aplicación peticlinic_test , es decir las pruebas unitarias de creación, actualización, búsqueda y eliminación de dueños. Todo esto deberá realizarse en coordinación con su equipo de trabajo usando Git



CASO 3 :
Deberá realizar la pruebas unitarias de la tabla specialities en la clase SpecialityServiceTest en la aplicación peticlinic_test , es decir las pruebas unitarias de creación, actualización, búsqueda y eliminación de especialidades. Todo esto deberá realizarse en coordinación con su equipo de trabajo usando Git

CASO 4 :
Deberá realizar la pruebas unitarias de la tabla visits, en la clase VisitServiceTest en la que aplicación peticlinic_test , es decir las pruebas unitarias de creación, actualización, búsqueda y eliminación de visitas. Todo esto deberá realizarse en coordinación con su equipo de trabajo usando Git

CASO 5:
Deberá realizar las pruebas unitarias de la tabla types en la clase TypeServiceTest (o PetTypeServiceTest) en la aplicación petclinic_test, es decir las pruebas unitarias de creación, actualización, búsqueda y eliminación de tipos de mascotas (Type). Todo esto deberá realizarse en coordinación con su equipo de trabajo usando Git.

CASO 6:
Deberá realizar las pruebas unitarias de la tabla vet_specialties en la clase VetSpecialtyServiceTest en la aplicación petclinic_test, es decir las pruebas unitarias de asignación de especialidades a veterinarios, búsqueda de especialidades por veterinario, búsqueda de veterinarios por especialidad, y eliminación de la relación veterinario-especialidad. Todo esto deberá realizarse en coordinación con su equipo de trabajo usando Git.


Se deberá presentar las evidencias de las pruebas realizadas en el informe de laboratorio y la ruta del proyecto Git creado
